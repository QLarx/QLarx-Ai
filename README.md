# QLarx AI 2.0 — файлы без папок

## GitHub Pages: загрузка в корень репозитория

В корне ZIP лежат все файлы интерфейса отдельно:
- `index.html`
- `styles.css`
- `app.js`
- `config.js`

Распакуйте архив на компьютере и загрузите именно эти четыре файла в корень репозитория `QLarx-Ai` через **Add file → Upload files**. GitHub Pages не разложит загруженную папку автоматически — загружайте файлы, находящиеся внутри неё. `README.md` можно также положить в корень.

## Подключение ИИ — отдельный сервер обязателен

GitHub Pages обслуживает только статические файлы и не запускает Node.js. Чтобы ИИ отвечал, backend надо развернуть на отдельном Node.js-хостинге.

Для backend в архив также положены файлы без вложенной папки:
- `backend-server.js` — серверный код;
- `backend-package.json` — зависимости и команды;
- `backend-env-example.txt` — пример переменных окружения.

На отдельном хостинге создайте backend-проект и поместите серверный код как `server.js`, а `backend-package.json` переименуйте в `package.json`. Хостинг должен иметь доступ к обоим файлам в корне своего проекта. В `package.json` команда запуска — `npm start`. Добавьте `OPENAI_API_KEY`, `OPENAI_MODEL` и `ALLOWED_ORIGINS` в настройки окружения хостинга; не публикуйте секретный ключ в GitHub. Для `ALLOWED_ORIGINS` используйте `https://qlarx.github.io`.

После публикации backend проверьте `https://ВАШ-БЭКЕНД/api/health`. Затем укажите его URL в `config.js`:

```js
window.QLARX_CONFIG = { apiBase: "https://ВАШ-БЭКЕНД" };
```

Закоммитьте обновлённый `config.js` в корень GitHub-репозитория.

## Что включено

- Тёмный адаптивный дизайн с синими и фиолетовыми акцентами.
- Русский интерфейс, выбор предмета и класса.
- Вызов ИИ через backend API, пошаговые объяснения.
- Локальная история запросов и копирование ответа.

**Важно:** только файлы интерфейса работают на GitHub Pages. Для реальных ответов ИИ необходим отдельный backend и действующий API-ключ. Ключ нельзя помещать в `config.js` или другие публичные файлы.
